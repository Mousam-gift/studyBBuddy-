# AI Smart Assistant (Gemini AI Agent)

A multi-domain AI assistant built using Google's Gemini API.  
The agent can provide help in:

- Education
- Health information
- Sustainability
  
## Features

- Domain classification
- Gemini LLM integration
- Smart routing agent
- Clean modular architecture

## Tech Stack

Python  
Google Gemini API  
Prompt Engineering  

## Installation

git clone https://github.com/yourusername/ai-smart-assistant

cd ai-smart-assistant

pip install -r requirements.txt

## Run

python app.py
